QUICK START
================================================================================

1. Install:
   npm install

2. Setup Supabase:
   supabase db push

3. Deploy functions:
   supabase functions deploy configure-agents
   supabase functions deploy ingest-documents
   supabase functions deploy ingest-excel
   supabase functions deploy query-agent

4. Set environment variables:
   VITE_SUPABASE_URL=<url>
   VITE_SUPABASE_ANON_KEY=<key>

5. Start:
   npm run dev

6. Test:
   Navigate to http://localhost:5173/onboarding/q1

See QUICK_START.md for detailed instructions.

================================================================================
EDGE FUNCTIONS
================================================================================

configure-agents
  Input: company_id, q1_industry_type, q2_company_size, q3_pain_points, q5_ai_style
  Output: configured_agents[], priority_agent
  Logic: Reads config, determines agents, creates configurations

ingest-documents
  Input: knowledge_base_id, filename, file_type, file_url
  Output: document_id, status
  Logic: Creates document record, triggers background processing

ingest-excel
  Input: company_id, filename, file_url, sheet_names
  Output: excel_id, status
  Logic: Creates data source, triggers background parsing

query-agent
  Input: company_id, agent_id, interaction_type, input_data
  Output: response, confidence, sources
  Logic: Validates agent, retrieves context, calls LLM
